## Diagnosis and changes

The initial SQL profile measured 58,634 preparation method calls and 149,529
publication-owner calls. These are instrumented local method entries, not provider
usage. Repeated checkpoints and single-artifact work dominated the owner path.

- Membership reduction now checks its pinned observation prefix once and retains
  whether it contains Product/context membership evidence. Empty membership work
  no longer scans all Products and contexts; inferred prior contexts and missing
  relationships still follow their existing reduction rules.
- Artifact preparation and public export preparation advance up to four bounded
  records before their guarded checkpoint. Phase changes and composition parents
  still wait for committed child receipts. Public export components still contain
  exactly one record; the existing call, byte and dependency limits remain enforced.
  Artifact batching stops once projection plus lifecycle bytes exceed 64 KiB:
  at most three small units can precede one existing maximum-size unit, leaving
  headroom within the 1 MiB staging bound for receipts and checkpoint metadata.
- The callback resource guard now wraps `CATALOGUE_EXPORTS` as well as evidence
  and image buckets. A failing test reproduced its missing four-open-body limit;
  the parameterized regression passes for all three buckets.
- New source-history records and their entity counts share one guarded transaction;
  retaining an observation reuses the lookup that preserves its first publication.
  Game entity scopes use the existing bounded 32-record scan as one SQL write.
- Backup snapshots discover table columns and read up to 16 ordered rows within
  1 MiB, preserving single large legacy rows. Private rows keep their byte limit.
  The same complete ordered row stream is hashed before export and after real SQL
  restore. Tests compare the former single-row digest, reject changed restore
  evidence, and exercise SQL pagination with UTF-8 data and a large legacy row.

A temporary diagnostic copy of the Product test used a 300-second window solely
