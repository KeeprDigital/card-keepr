# Consumers receive accepted facts; administration retains the evidence

Accepted through [Decide consumer visibility and evidence-complete approval](https://github.com/KeeprDigital/card-keepr/issues/213#issuecomment-5558597280), which holds the complete decision. Published supplemental Cards and Printings appear by default in consumer queries and exports, with explicit unknowns but without evidence labels, provenance or source-health filters; admission and approval carry the responsibility for sufficient evidence so consumers need not evaluate it themselves.

A complete, paginated administration API exposes the immutable candidate, semantic before/after differences and supporting evidence, including evidence-only changes, images, every entity and relationship, exceptions, exclusions and carry-forward. Whole-candidate approval binds to that candidate and its expected Catalogue Revision without mandatory per-item acknowledgements; an app can be added later. This moves review complexity into administration while preserving inspectability and publication integrity.

[ADR 0015](0015-bounded-durable-publication-per-game.md) subsequently makes each candidate specific to one game and binds approval to its expected Game Catalogue Revision. Other games can publish independently without invalidating approval; reads and exports still pin a consistent catalogue composition.

This supersedes consumer-export provenance requirements in ADRs 0001 and 0002 and prior opt-in consumer-provenance assumptions, while preserving explicit unknowns for in-scope card facts, retained evidence, operational history and recovery protection. [ADR 0014](0014-card-content-without-tournament-eligibility.md) subsequently removes tournament eligibility, including legality statuses and unknown-scope processing, from both the consumer contract and required administrative review. Definitions change in place before Go-Live under ADR 0008. This records a planning decision, not an implemented API or export change.
