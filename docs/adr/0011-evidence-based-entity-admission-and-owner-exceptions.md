# Entity admission preserves evidence and permits explicit owner exceptions

Accepted 6 September 2026 through [Decide supplemental entity admission and conflict handling](https://github.com/KeeprDigital/card-keepr/issues/211#issuecomment-5556519627), which holds the complete policy. Game Profiles define evolving admission requirements, source-specific rules establish how evidence satisfies them, and Entity Proposals retain unresolved intake outside published Catalogue Data; qualified sources can admit automatically while the owner can explicitly resolve exceptions using retained evidence, including personal attestation.

This replaces the assumption that supplemental evidence can only enrich existing entities without treating existing-entity Curated Revisions as a creation mechanism. Explicit owner exceptions preserve operational flexibility without fabricating publisher confirmation or bypassing required catalogue structure; retaining proposal, conflict and override history adds review state but makes later reconsideration and publisher confirmation possible without losing provenance or changing established IDs. Admission remains separate from Catalogue Candidate approval, and uncertainty blocks publication only where it cannot be isolated consistently. This records a planning decision, not an implemented intake path.
