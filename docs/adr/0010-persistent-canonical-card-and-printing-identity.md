# Canonical identity survives changes in source evidence

Accepted 6 September 2026 through [Decide canonical Card and Printing identity across sources](https://github.com/KeeprDigital/card-keepr/issues/210#issuecomment-5556048893), which holds the complete decision, correction policy and evidence limits. Catalogue and inventory consumers need stable references to individual Printings even when sources, publisher numbers or identifying facts change; persistent canonical IDs and retained evidence mappings provide that stability, while each Game Profile defines Card equivalence and sufficient matching evidence.

This replaces identity derived from mutable compatibility fields, including Source Lineage, and rejects simply removing lineage from the existing hash: doing so neither establishes cross-source equivalence nor repairs the reproduced Fusion World base/alternate collision. Persistent mappings add state that must survive backup/recovery, and auditable corrections require consumers to handle redirects and ambiguous splits, but they avoid making changing source evidence silently change consumer identity. ADR 0008's pre-Go-Live definition policy and operational recovery protection remain unchanged; this records a planning decision, not an implemented migration.
